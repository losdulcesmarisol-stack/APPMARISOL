# SEO autónomo de dulcesmarisol.es

- `INSTRUCCIONES.md` — manual que sigue la IA en cada ejecución diaria.
- `aprendizajes.md` — memoria: preferencias de Marisol y qué funciona.
- `cambios.json` — registro de cada cambio aplicado (antes/después) para deshacerlo.
- `historial/` — un informe por día.
- `datos/` — auditorías técnicas en JSON.
- `scripts/auditoria.py` — auditoría técnica de todas las URLs del sitemap.

Las propuestas se aprueban marcando casillas en las issues con etiqueta
`seo-propuesta` de este repositorio.
